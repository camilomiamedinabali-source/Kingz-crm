SOLUTION #2: Auto-Select Dropdown Value When Refreshing Pickers

File: public/index.html
Location: Line 268 (refreshLogPickers function)

BEFORE (BROKEN):
```javascript
const priv=DB.students.filter(s=>s.schoolId==="private");
$("#logPrivateStudent").innerHTML=priv.length?priv.map(s=>`<option...`).join(""):`...`;
// Dropdown populated but NOT selected - newly added student invisible!
buildRoster();
```

AFTER (FIXED):
```javascript
const priv=DB.students.filter(s=>s.schoolId==="private");
const pSel=$("#logPrivateStudent");
pSel.innerHTML=priv.length?priv.map(s=>`<option...`).join(""):`...`;
// NEW LOGIC: Auto-select first private student when conditions met
if(logState.type==="private"&&priv.length&&!pSel.value){
  pSel.value=priv[0].id;
}
buildRoster();
```

Smart Logic Explanation:
- if(logState.type==="private") - only in private mode
- &&priv.length - only if private students exist
- &&!pSel.value - only if dropdown currently has no selection
- pSel.value=priv[0].id - select first private student

This ensures:
- Newly added students automatically appear in roster
- Doesn't override existing user selections
- Respects previous manual dropdown changes
- No unnecessary re-selections
